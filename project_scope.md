\# Coffee Shop Sales Analytics Project

\#\# Project Overview

This project analyzes transactional sales data from a multi-location coffee shop using PostgreSQL, Power BI, Python, and Excel.

The purpose of the project is to identify business trends, evaluate store performance, understand customer purchasing behavior, and provide actionable recommendations for management.

\---

\#\# Objectives

\- Build a PostgreSQL database from raw sales data.  
\- Validate and clean imported data.  
\- Analyze key business metrics using SQL.  
\- Develop an interactive Power BI dashboard.  
\- Reproduce analyses using Python (Pandas).  
\- Present findings in a professional business report.

\---

\#\# Dataset

The dataset contains transactional sales information including:

\- Transaction information  
\- Product information  
\- Store information  
\- Date and time information  
\- Revenue  
\- Quantity sold
