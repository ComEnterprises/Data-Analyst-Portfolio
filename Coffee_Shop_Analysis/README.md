# ☕ Coffee Shop Analytics

An end-to-end data analytics project built with **PostgreSQL, Python, and Power BI** to analyze coffee shop sales data and generate business insights.

---

# Project Overview

This project demonstrates a complete analytics workflow, beginning with raw transactional sales data and ending with an interactive business dashboard. The goal was to practice the same types of tasks commonly performed by entry-level data analysts, including data validation, SQL analysis, Python automation, and dashboard development.

The project follows a typical analytics pipeline:

**Raw CSV → PostgreSQL → SQL Analysis → Python Automation → Power BI Dashboard**

---

# Business Objective

The objective of this project was to answer common business questions such as:

* Which stores generate the most revenue?
* Which product categories perform the best?
* What are the highest-selling products?
* When are sales at their busiest?
* What trends appear across days, hours, and months?

The resulting analysis can help managers make decisions about staffing, inventory, promotions, and overall store performance.

---

# Dataset

The project uses a transactional coffee shop sales dataset containing approximately **149,000 sales records**.

Each transaction includes information such as:

* Transaction ID
* Date and time
* Store location
* Product category
* Product
* Quantity sold
* Unit price
* Revenue
